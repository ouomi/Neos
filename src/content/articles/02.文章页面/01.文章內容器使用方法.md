 证。

 Markdown 中的使用方式

 ### 折叠容器 md-details

 ```html
<details class="md-details">
  <summary>点击查看详情</summary>
  <div class="md-details-content">
    <p>这里是折叠起来的内容。</p>
    <p>展开后即可看到。</p>
  </div>
</details>
 ```

 如果希望默认展开：

 ```html
<details class="md-details" open>
  <summary>默认展开的内容</summary>
  <div class="md-details-content">
    <p>这里是正文。</p>
  </div>
</details>
 ```

 ### 绿色提示容器 md-tip

 ```html
<div class="md-tip">
  <p>这是一条提示信息。</p>
</div>
 ```

 ### 黄色警告容器 md-warning

 ```html
<div class="md-warning">
  <p>执行下面的操作前，请先备份重要数据。</p>
</div>
 ```

 ### 红色错误容器 md-error

 ```html
<div class="md-error">
  <p>该操作可能造成不可恢复的数据丢失。</p>
</div>
 ```

 ### 居中容器 md-center

 ```html
<div class="md-center">
  <p>这段文字会居中显示。</p>
  <img src="/images/example.jpg" alt="示例图片">
</div>
 ```

 ### 手机竖屏图片容器 md-pp

 ```html
<div class="md-pp">
  <img src="" alt="手机竖屏截图">
</div>

<div class="md-pp">
  <img src="">
</div>
 ```

 md-pp 会保持图片原始宽高比例，将图片最大高度限制为视口高度的 70% 或 36rem，取其中较小值，避免竖屏图片占据过多页面空间。
